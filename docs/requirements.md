# 要件定義

## 1. 定義

### 対象ユーザー

Macで複数のLinuxサーバ、ネットワーク機器、踏み台を管理し、普段のターミナルとしてiTerm2を使う個人ユーザー。

### 用語

- 接続定義: OpenSSH config内の具体的な `Host` 別名
- メタデータ: RelayDeckだけが持つフォルダ、タグ、お気に入り、表示名、メモ
- 起動: iTerm2に `ssh <Host別名>` を渡すこと

## 2. 機能要件

| ID | 要件 | MVP |
|---|---|---:|
| F-01 | `~/.ssh/config` と `Include` を読み込む | 必須 |
| F-02 | 接続先の一覧、詳細を表示する | 必須 |
| F-03 | 全文検索する | 必須 |
| F-04 | フォルダ、タグ、お気に入りを編集する | 必須 |
| F-05 | 最近の接続と接続回数を表示する | 必須 |
| F-06 | iTerm2の新規ウィンドウまたはタブでSSHを開始する | 必須 |
| F-07 | SSH configを手動再読込する | 必須 |
| F-08 | RDP、VNC、HTTP、HTTPSを外部アプリで開く | 後続 |

## 3. 非機能要件

- SSH認証情報を保存しない
- SSH configを無断で変更しない
- AppleScriptにユーザー由来文字列をソースコードとして埋め込まない
- 1000接続程度まで検索が即時に応答する
- ネットワークがなくても全機能が動作する
- メタデータファイル破損時はエラーを表示し、SSH config自体には影響を与えない

## 4. SSH configの扱い

- `Host foo bar` は `foo` と `bar` を別接続として表示する
- `Host *`、`Host *.example.com`、否定パターンは一覧対象外とする
- 各Hostブロック内の `HostName`、`User`、`Port`、`ProxyJump`、`IdentityFile` を表示用に読む
- OpenSSHの最終的な優先順位解決を再実装しない。接続時は必ずHost別名をシステムの `ssh` に渡す
- `Match` ブロックは一覧生成対象外とする
- `Include` は循環を検知し、同一ファイルを重複読込しない
